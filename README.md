# NIKKA | Minimalist Zen ToDo Application

> **Daily Harmony & Mindful Tasks** — A serene, clean, and responsive Japanese Zen-themed ToDo application built with pure HTML5, modern CSS3, and Vanilla JavaScript with 100% English interface.

---

## 🌸 Aesthetics & Design Philosophy

NIKKA combines the timeless aesthetics of Japanese minimalism with an intuitive, clutter-free English interface:

- **Ma (間 - Negative Space)**: Spacious, calm layout without visual clutter or distraction.
- **Washi & Sumi Themes**: Light mode inspired by the warmth of textured washi paper, and dark mode inspired by deep charcoal sumi ink.
- **Red Seal Badges (Hanko Stamp)**: Minimalist vermilion stamps for urgent priorities and brand accents.
- **Zen Sound FX**: Pure native audio synthesis using the Web Audio API — traditional wooden clack (*Hyoshigi*) for actions and resonant singing bowl chime (*Rin Bell*) for completions.
- **Daily Reflections**: Curated Zen quotes and mindful wisdom to inspire focus.

---

## ✨ Features

- 🎏 **Task Management**:
  - Add tasks with category tagging (💼 Work, 🎋 Personal, 📖 Study, 🍵 Health, 🎨 Creative).
  - 3 Priority tiers (Calm, Normal, Urgent).
  - Due date picker with Overdue and Today indicators.
  - Subtasks checklist with real-time completion tracking.
  - Pin important tasks to the top.
  - Inline title editing (double-click any task title).
- ⏱️ **Zen Focus Mode (Pomodoro Timer)**:
  - Minimalist circular timer with presets (25m Focus, 5m Short Break, 15m Long Break, 50m Deep Work).
  - Single-task focus linking directly from any task item.
- 📊 **Daily Progress & Harmony Meter**:
  - Live progress bar and completion rate indicator.
  - Slide-over drawer with summary statistics.
- 💾 **Data Persistence & Portability**:
  - Automatic `localStorage` saving.
  - One-click JSON backup export and restore.
  - Load sample tasks option for quick testing.
- 📱 **Fully Responsive**:
  - Fluid mobile, tablet, and desktop adaptive design.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Enter` (in task input) | Add new task |
| `/` or `Ctrl + K` / `Cmd + K` | Jump to search bar |
| `Escape` | Close timer modal or settings drawer |
| `Double Click` (on title) | Inline edit task title |

## 🚀 How to Run
